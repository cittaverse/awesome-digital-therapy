# Metamemory Intervention RCT Landscape (2025-2026)

> 元记忆干预随机对照试验证据全景 — GEO #39 证据深潜
>
> 更新日期: 2026-03-18 | 验证等级: V2 (多来源交叉确认)

## Executive Summary

2025-2026 年出现了一批高质量元记忆 (metamemory) 干预 RCT，标志着该领域从理论验证阶段进入**数字化规模化**阶段。核心趋势：

1. **移动端元记忆训练 RCT 首次发表** — ET-101 (Cogthera) 多中心 RCT 证实移动 App 元记忆训练对 MCI 有效
2. **长期随访数据出现** — 15 个月前瞻性研究证实持续获益
3. **自助式数字化方案可行** — 自导式电子学习改善健康老年人元记忆
4. **日常记忆 + 元认知综合干预** — EMMI RCT 证实多维干预有效

## 核心研究汇总

### 1. ET-101 (Cogthera) — 移动端元记忆认知训练 RCT

| 项目 | 详情 |
|------|------|
| **引用** | Kang S, et al. (2026). Efficacy and Safety of Mobile App–Based Metamemory Cognitive Training for Mild Cognitive Impairment: Multicenter Randomized Clinical Trial. JMIR mHealth uHealth. |
| **发表** | 2026-01-19, JMIR mHealth uHealth |
| **设计** | 多中心 RCT, ET-101 vs 假设备对照 |
| **人群** | MCI 老年人, N=99 (ET-101: 49, 对照: 50) |
| **干预** | 24 周移动 App 元记忆训练 |
| **主要结局** | ADAS-Cog-14 应答者比例 (维持或改善) |
| **核心结果** | ET-101 组 ADAS-Cog-14 应答者比例显著高于对照组 (P=.002) |
| **次要结果** | 记忆域 + 语言域均有显著改善 |
| **安全性** | 未报告严重不良事件 |
| **ClinicalTrials.gov** | NCT05938426 |
| **验证等级** | V1 (基于搜索结果摘要) |

**对 CittaVerse 的意义**:
- ✅ 直接证实移动端元记忆训练对 MCI 有效 — 支持 CittaVerse 技术路线
- ✅ 24 周干预周期 — CittaVerse Pilot 14 天是可行的最小验证
- 🎯 **差异化**: ET-101 聚焦纯认知训练; CittaVerse 结合**叙事 + 元记忆**，更接近 EMMI 模式
- 🎯 **竞争分析**: ET-101 已获 FDA breakthrough device designation (韩国团队), 商业化路径清晰

### CittaVerse 独特定位

**唯一将叙事疗法 × 元记忆训练 × AI 引导三者结合的产品方案。**

- ET-101 证实了移动端元记忆训练的有效性 → CittaVerse 在此基础上叠加叙事维度
- EMMI 证实了多维干预的优越性 → CittaVerse 用 AI 实现 EMMI 的可扩展版本
- Rose 证实了自导式模式的可行性 → CittaVerse 的微信端天然支持
- Limbic 证实了 genAI 个性化的参与度提升 → CittaVerse 的 LLM 引导叙事

## 证据空白与 CittaVerse 机会

1. **叙事 + 元记忆联合干预 RCT = 0** — 文献空白，CittaVerse Pilot 可成为首个
2. **中国老年人社区数字疗法 RCT 稀少** — 微信生态部署是差异化壁垒
3. **AI 引导 vs 传统引导对比 RCT = 0** — CittaVerse 可设计 AI vs 人工对照臂
4. **叙事质量自动评估工具 = 0 商业化** — CittaVerse 的 6 维度叙事评分器是潜在技术壁垒
